# The-best-economics

Tämä repo sisältää yhden dokumentin: [`haastattelukysymykset-2021-09-20.md`](haastattelukysymykset-2021-09-20.md),
kysymyslistan 20.9.2021 pidettyä yhteishaastattelua varten. Aiheena on Suomen
talous ja yritykset: BKT-kasvu, Suomen Pankin näkemys nousukauden kestosta,
yritysten "koronamoodi", Pk-yritysbarometri, kasvuyritysten vienti
ulkomaille, ilmastonmuutos liiketoimintamahdollisuutena sekä vienti ja sen
rahoitus.

Dokumentti oli alun perin Microsoft Wordilla kirjoitettu ja verkkosivuna
(.htm) viety muistio. Se on nyt muunnettu puhtaaksi Markdowniksi ilman
Wordin generoimaa muotoilua, ja alkuperäinen .htm-tiedosto tukikansioineen
on poistettu.
